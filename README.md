# voice-task-reminder

純 HTML、CSS、JavaScript 的手機優先待辦 App。沒有框架、資料庫、AI、Web Push 或登入系統。標題依需求為「AI 語音待辦提醒系統」，時間解析本身為規則式。

## 開啟預覽

在此資料夾執行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

電腦：http://localhost:8000 。手機與電腦連同一 Wi-Fi，在 Safari 開啟 http://電腦區域網路IP:8000 。目前電腦 IP 為 172.20.10.14；換網路後需重新確認。保持電腦與伺服器運作，必要時允許防火牆的區域網路連線。

語音按鈕使用瀏覽器 SpeechRecognition / webkitSpeechRecognition，語言為 zh-TW。實際支援、麥克風權限與 HTTP 限制依瀏覽器而定。手機區網 HTTP 預覽若無法使用語音按鈕，可直接點輸入框使用 iPhone 鍵盤麥克風，或打字；解析相同。語音辨識由瀏覽器提供，可能使用瀏覽器供應商服務；本 App 的時間解析不呼叫任何 API。

## 時間與保存規則

以裝置本地時區計算。週一為一週開始；「這禮拜」指本週，「下週」指下個週一開始的一週。因此這禮拜五在週日輸入時會歸為已到期。無時段的指定日期預設 08:00；只有鐘點時預設今天。未辨識到時間或時間不合法時顯示未設定。

資料只保存在目前瀏覽器的 localStorage；不同裝置、瀏覽器、網址來源各有獨立資料，不會同步。清除網站資料也會刪除任務。頁面每 30 秒與回到前景時更新分類，不提供背景通知。

Google Calendar 按鈕開啟已帶入資訊的事件頁，需使用者最後儲存。Apple 按鈕下載 .ics，使用 iPhone 或 macOS 的行事曆開啟匯入。事件長度為 30 分鐘，UTC 時間由行事曆轉成當地時區。沒有提醒時間不顯示行事曆按鈕。事件不額外指定通知警示，依行事曆設定處理。
